# VIDA 90

**V**itória · **I**ntensidade · **D**isciplina · **A**ção — app de hábitos em ciclos de 3 meses de calendário.

Versão portátil em arquivo único (`vida-90.html`): 100% offline, sem conta e sem servidor. Os dados ficam salvos no próprio navegador (localStorage), com exportar/importar `.json` para levar para outro aparelho.

## Como usar

- Abra o `vida-90.html` em qualquer navegador, no computador ou no celular — ou use o link do GitHub Pages deste repositório.
- No celular, "Adicionar à tela inicial" transforma o app em ícone, como um aplicativo.
- Detalhes completos no `LEIA-ME.txt`.

## O app

- **Diária:** Manhã/Tarde/Noite, com seletor de hábito ou tarefa livre em cada linha
- **Semanal:** rodas de 7 dias + últimos dias, com VIC/DER automáticos
- **Mensal:** roda de 31 dias tocável, objetivo do mês e Fazer Menos / Fazer Mais editáveis
- Hábitos com cores e ciclo próprio (dia do ciclo, dias restantes e %)
